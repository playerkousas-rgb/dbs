後台維護說明（給未來維護者）
主考委任系統的資料結構、工作表、Config、常見維護操作。
系統架構：Next.js（Vercel）前端 → Google Apps Script（doGet/doPost）→ Google Sheets 資料庫。

一、核心設計原則（務必先理解）
BadgeCodes 是唯一真理：所有「章」的定義來源。
full_title 是全系統的章識別鑰匙：唯一、不重複。
報考比對、主考資格、Matrix 欄位，全部用 full_title。
badge_code 可重複（同章細分項共用，如語言英語/普通話都是 SIN），這是正確設計，用於證書編號。
full_title 只在 BadgeCodes 人手填一次，其餘（Matrix 表頭、Examiners）全部由程式複製，永不重打 → 全形/半形括號不會造成 BUG。
報考系統只讀 Examiners 表，不讀 Matrix。Matrix 只是給人看 + 維護用的視圖。
二、主考相關工作表
1. BadgeCodes（章定義，唯一真理）
欄	說明
badge_name	中文章名（印證書用）
badge_code	證書代碼（可重複；同章細分共用）
badge_name_en	英文章名
category	類別：興趣 / 技能 / 服務 / 教導 / 其他
category_en	類別英文
full_title	唯一鑰匙 = 「類別 - 章名」或含細項「類別 - 章名 (細項)」
active	TRUE 才會啟用
duplicate	沿用慣例
Remark	備註
2. ExaminerMatrix（人看的矩陣視圖）
第 1 列 = 表頭：A=姓名、B=單位、C 之後 = 各章的 full_title（由「🔧 重建 Matrix 表頭」工具產生）。
第 2 列起 = 每位主考一行，格內填 D（區主考）/ G（旅團主考）/ 空白。
維護者改這裡：要加/刪某主考某章資格，直接改格子，再按「🔄 同步」。
3. Examiners（機器讀的真實來源，報考用）
欄	說明
examiner_id	E-xxxxx
name	主考姓名（含稱謂，須與 Matrix 一致）
unit	單位，格式「港島第XX旅」（不是 G-0XX）
email / phone	聯絡
district_badges	D 級資格章清單（full_title，逗號分隔）
group_badges	G 級資格章清單（full_title，逗號分隔）
term_start / term_end	任期
status	ACTIVE 才有效
current_load / max_load	負荷 / 上限
updated_at	更新日
⚠️ Examiners 由 ExaminerMatrix 同步產生（單向 Matrix → Examiners）。
不要手改 Examiners 的章清單，要改去改 Matrix 再同步，否則下次同步會被覆蓋。
（email/phone/任期/負荷等個人欄位同步時會保留。）

4. ExaminerAppointments（主考申請暫存）
欄	說明
appointment_id	APT-yymmdd-xxxx
examiner_id	批准後回填
badge_name	申請的章（含級別字串，給人看）
term_start / term_end	批准後回填
approved_by / approved_at	審批人 / 時間
application_form_url	證書附件連結
status	PENDING_ADC_APPROVAL / APPROVED / PARTIALLY_APPROVED / REJECTED
renewal_reminder_sent	續期提醒
notes	關鍵：用「欄位：值 | 欄位：值」格式存所有申請細節，含 badge_scopes（逐章 D/G 的 JSON）
5. Groups（旅團）
group_id（G-0XX）、group_number（XX）、group_name、leader_*、district_area。
主考申請存的是 group_id，但寫入 Examiners 時由 normalizeUnit_() 轉成「港島第XX旅」。

四、常見維護操作
A. 新增專章
BadgeCodes 最下加一列（active=TRUE，細分章自填唯一 full_title）。
選單「✍️ 自動補 full_title」（補一般章空白）。
選單「🔧 重建 Matrix 表頭」（新章成為 Matrix 新欄，保留現有 D/G）。
B. 停用某章
BadgeCodes 該列 active 改成 FALSE → 報考/申請頁不再出現。
（可選）再按「🔧 重建 Matrix 表頭」移除該欄。
C. 取消某主考某章資格
ExaminerMatrix 把該格的 D/G 清空 → 按「🔄 同步主考資料」。
D. 主考姓名/單位不一致導致重複行
確保 Matrix 與 Examiners 的 name 完全一致（含稱謂）。
單位統一用「港島第XX旅」。
修正後按「🔄 同步」。
E. 同步行為說明
「🔄 同步」= syncExaminerMatrixDirect：清空 Examiners 後，依 Matrix 重建。
所以 Matrix 必須涵蓋所有要保留的主考；ADC 審批時會自動補欄 + 自動同步，一般無需手動。
