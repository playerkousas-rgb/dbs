筲箕灣區專科徽章系統 — 使用指南
適用對象：考生／家長、主考、ADC（助理區總監）、DBS（專章秘書）
網址：https://dbs-teal-iota.vercel.app

🧒 一、考生 / 家長
你可以做什麼
功能	入口
報考專章	首頁 →「📝 報考專章」
查詢考核進度	首頁 →「🔍 進度查詢」（輸入 申請編號 + YMIS 童軍編號）
查看待領證書	首頁 →「📋 待領證書」
報考流程
進入「報考專章」，填寫個人 / 旅團 / 專章資料。
選擇考驗安排：
自行安排主考：只能選本旅團且具該章資格的主考。
由區會派發：系統自動安排主考。
其他（認可訓練班 / 專章考驗日 / 證書換章）：不需派主考。
送出後，系統自動通知家長與團長確認。
雙方確認 → 區會批核 → 指派主考 → 主考考核 → 合格製證書 → 領取。
你的責任
確保填寫的 YMIS、電郵、家長電郵正確（通知靠它）。
妥善保存申請編號，查詢進度時要用。
👨‍🏫 二、主考
你可以做什麼
功能	入口
申請成為主考	首頁 →「👨‍🏫 主考申請」
查詢申請審批進度	首頁 →「🗂️ 主考專區」→ 主考申請進度查詢
接受 / 拒絕考核指派	電郵內的連結
回報考核成績	電郵內的連結
申請主考流程
進入「主考申請」，填寫：
姓名（只填名字）+ 稱謂（先生／女士／不適用，系統會自動組合）
電郵、電話、所屬旅團、職級、年資
勾選想申請的專章，每章再選級別：
旅團主考 (G)：只考核本旅團童軍。
區主考 (D)：可考核全區童軍。
填寫資歷、上傳證書附件（建議附上，加快審批）。
送出後會收到申請編號（APT-xxxxxx-xxxx），ADC 會收到通知。
可隨時用申請編號到「主考專區」查進度。
ADC 審批後，你會收到電郵，列明獲委任 / 未批准的專章與級別。
收到考核指派後
電郵內有「接受」「拒絕」連結，請盡快回應。
考核完成後，用電郵連結回報成績（合格／不合格 + 備註）。
你的責任
只考核自己獲委任級別範圍內的考生（G 主考勿跨旅）。
在考核限期（90 天）內完成並回報。
申請時如實填寫資歷。
🧑‍💼 三、ADC（助理區總監）
你可以做什麼
功能	入口
審批主考委任申請	首頁 →「🗂️ 主考專區」→ ADC 審批後台（輸入 ADC 密鑰）
審批流程
收到「新主考委任申請」電郵 → 點開「主考專區」。
切到「🔐 ADC 審批後台」分頁，輸入 ADC 密鑰登入。
看到每位申請人的：個人資料、資歷說明、證書附件、逐章申請的級別 (D/G)。
逐章勾選要批准的專章（不打勾＝否決該章），可用「全選／全不選」。
按「✅ 確認審批」。
系統會自動做的事（你不用管）
把批准的章寫入主考名冊（Examiners + ExaminerMatrix）。
自動同步名單。
寄審批結果給申請人。
寄通知給 DBS。
審批規則（系統自動處理）
申請人原本已是某章某級主考 → 自動略過（不重複）。
同章但級別改變（G↔D）→ 自動更新為新級別。
全新的章 → 加入名冊。
你的責任
根據資歷與證書判斷是否勝任，逐章批准 / 否決。
妥善保管 ADC 密鑰。
🗂️ 四、DBS（專章秘書）
你可以做什麼
功能	入口
報考申請審批、指派主考、證書管理、報表	首頁 →「⚙️ 秘書後台」（輸入秘書密鑰）
主考名單管理、新增專章、同步	Google 試算表「🏕️ 主考管理」選單
日常重點
報考審批 / 派主考 / 證書：在「秘書後台」操作（沿用原流程）。
主考委任：ADC 在 /adc 審批後已自動寫入並同步，你只會收到通知信知悉，通常不用手動同步。
新增專科徽章（總會出新章時）：見《新增專章 SOP》一節。
取消主考資格：到試算表 ExaminerMatrix 把該主考該章的格清空，再按選單「🔄 同步主考資料」。
新增專章 SOP（簡版）
在 BadgeCodes 工作表最下面加一列（位置不影響系統）：
必填：badge_name、badge_code、badge_name_en、category、category_en、active=TRUE
full_title 可留空（系統自動補）；細分章（如語言分英語/普通話）需自己填含細項的唯一 full_title。
試算表選單按「✍️ 自動補 full_title」。
試算表選單按「🔧 重建 Matrix 表頭」。
完成，報考頁與主考申請頁會立即出現新章。
你的責任
維護 BadgeCodes（章的增減）。
處理取消主考、異常名單。
保管秘書密鑰。
